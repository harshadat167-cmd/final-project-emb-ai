# Final Project: Emotion Detection Application

## Project Description
The Final Project is an Emotion Detection application that analyzes text and identifies the emotions expressed in it using the IBM Watson NLP Emotion Detection service.

## Emotions Detected
- Anger
- Disgust
- Fear
- Joy
- Sadness

The application also identifies the dominant emotion based on the emotion scores.

## Technologies Used
- Python
- Flask
- Requests
- IBM Watson NLP service
- HTML, CSS, and JavaScript
- Unittest

## Project Files
- `EmotionDetection/emotion_detection.py` — Detects emotions from text.
- `EmotionDetection/__init__.py` — Initializes the Python package.
- `server.py` — Runs the Flask web application.
- `test_emotion_detection.py` — Contains unit tests.
- `templates/index.html` — Web interface.
- `static/mywebscript.js` — Handles user interaction.

## How to Run
1. Install the dependencies: `pip install flask requests`
2. Start the application: `python server.py`
3. Open `http://127.0.0.1:5000` in your browser.
4. Enter text and click **Run Sentiment Analysis**.
